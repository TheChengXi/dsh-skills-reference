# later-on：后续想法备忘

> 设计阶段识别但**此时不做**的事项，以及未来可能的演进方向。只记录想法，不做任何设计预留——需要时直接实现。

## 想法列表

- **L01**：内联样式迁移为独立样式文件 / CSS Module
  - 现状：`panel.tsx` 用内联 `style` 对象堆叠样式，本轮仅做 token 替换，未改结构。
  - 何时做：面板样式规模扩大（如新增复杂布局、动画）或可复用样式增多时。
  - 备注：迁移后仍应坚持 DSH 原生 token，不另造色板。

- **L02**：支持第三方自定义主题完整对齐
  - 现状：DSH 允许 `theme.overrideTokens` 覆盖 `--dsw-alias-*`；本轮面板引用真实 token，已天然随自定义主题走，无需额外处理。
  - 何时做：若发现某自定义主题对某 token 未定义、面板出现空值，再评估是否需要最小 fallback 策略。
  - 备注：遵循 AGENTS「Unperfect Code」——不提前做兜底，出真实边界再补。

- **L03**：错误横幅增强（图标、动画、重试按钮）
  - 现状：错误仅以状态条文字呈现，样式本次已对齐主题。
  - 何时做：错误态需要更强的操作引导（重试、展开详情）时。
  - 备注：届时新增元素直接沿用 DSH 语义 token。
